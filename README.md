# Latra
**Latra** is a webtool that converts characters into Latin letters.

## Supported Languages
1. Cyrillic
   1. Russian
   2. Ukrainian
   3. Kazakh
   4. Tajik
2. Greek
   - Greek (Modern)
3. Georgian
   - Georgian
4. Armenian
   - Armenian
